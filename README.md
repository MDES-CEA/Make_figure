# Diffraction & Spectra Studio

Outil web statique de génération de diffractogrammes empilés (DRX) et spectres Raman,
de spectres infrarouges, avec fiches de référence et personnalisation du rendu.

L'éditeur comprend une prévisualisation d'export normalisée, des exports PNG,
TIFF, SVG et PDF, ainsi que des contrôles typographiques directs sur la figure.

Les données restent locales au navigateur : aucun fichier n'est envoyé sur un serveur.

## Développement local

    npm install
    npm run dev

## Tests

    npm test

## Build

    npm run build

Application React + Vite + Tailwind CSS v4.
